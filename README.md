# 音声で答える（推薦ナビ用）

推薦ナビ（旧：面接練習アプリ。Google Apps Script）の音声入力用ページです。

Apps Script の画面は埋め込み表示のため、マイクが使えません。このページを練習画面から開き、話した内容を文字にして練習画面に送り返します。

- 質問データや API キーは含みません。
- 文字は練習画面（`*.googleusercontent.com`）にだけ送り、保存しません。
- 練習画面の「音声で答える」ボタンから開いたときだけ動きます。
- うまくいかなかったとき（音声認識のエラー、録音が途中で止まった、練習画面に送れなかった など）は、その種類と録音の秒数・字数だけを練習画面に知らせます（話した文字は含めません）。練習画面に送れなかったときは、この端末に残して次に開いたときに知らせます。
